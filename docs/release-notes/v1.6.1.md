## 修复（v1.6.1）

- **聊天里首次连接也能确认证书**：直接发消息遇到未信任证书时，聊天页弹出与设置页相同的指纹确认框；点「信任并重试」会保存指纹并自动重发刚才那条，不用重新输入；点「取消」则本次不发送、输入框内容原样保留。已信任但指纹变化时仍然直接拒绝，不会当成首次确认
- 设置里「使用 HTTPS」的说明改成准确说法：默认 HTTPS、服务端可 `--tls-selfsigned` 一键自签、首次连接核对指纹，不需要域名或证书机构；纯 HTTP 只建议在局域网/加密隧道里用
- `smoke_test.py` 支持 https：默认跳过证书校验（等价 curl -k）并打印警告，`--ca <pem>` 可严格校验；README 补了 https 自检与 `-k` 说明
- 版本 1.6.1 (23)

完整功能列表与用法见 [README](https://github.com/YYUN64/DeepSeekChat#readme)。
