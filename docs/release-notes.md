## 新增（v1.9.0）

- **多选照片**：输入框左侧「+」→「添加图片」可一次选多张（`PickMultipleVisualMedia`，API 33+ 走系统照片选择器，Android 12 等低版本自动回退到 SAF 多选）；每张都走原来的 1600px 缩放 + EXIF 转正 + JPEG 88；一条消息最多 6 张，超出的丢弃并提示「最多还能添加 N 张」；缩略图可逐个删除
- **添加文件**：输入框左侧「+」→「添加文件」，可读取任意文本文件（.txt .md .json .csv .log .xml .yaml .yml .ini .toml .py .js .ts .kt .java .c .h .cpp .go .rs .sh .sql .html .css 等）；含 NUL 字节判定为二进制并拒绝（提示先转成文本）；单文件超过 256 KB 截断并在末尾标注「…（已截断，原文件 N KB）」；最多同时附 5 个、总计 1 MB；附件以 chip（文件名 + 大小）显示，可删除
- 发送时把文件内容按「【文件：文件名】+ ```text 围栏」拼进这条 user 消息，随消息文本一起持久化（不存文件二进制、不写进会话 JSON 的独立字段）；拼接后整条消息超过 300 KB 时提示并只保留前几个文件
- 很长的用户消息在气泡里默认折叠（超过 2000 字点「展开全部」查看），避免几十 KB 的文件正文一次性排版卡顿
- 暂不支持：PDF / Word / Excel 解析（需要额外库），请先转成文本；「中途插话」等交互确定后再做
- 版本 1.9.0 (33)

完整功能列表与用法见 [README](https://github.com/YYUN64/DeepSeekChat#readme)。
