## 修复（v1.8.0）

- **MCP 开着就必须可用**：发送前先连一次拿工具；连不上、401、证书未信任或过滤后可用工具为 0 时**本轮不发送**，输入框内容保留，并给出明确错误（「MCP 服务器连接失败：…。本轮未发送」/「MCP 没有可用工具…本轮未发送」），不再悄悄退回普通对话
- **只在需要时连接、用完即断**：测试连接、发送前握手、每次工具调用都是独立请求（`Connection: close` + 显式 `disconnect`），不保持长连接、不缓存会话；打开 App/设置页不发任何 MCP 请求
- **连接中断有明确结果**：工具调用中途断连（IOException/TLS 断开）→ 卡片显示「连接中断」，tool 结果写入失败原因，并终止本轮（「MCP 连接已断开，工具调用中止」），不会把空结果当成功
- **测试连接超时 3 秒**：连接/读取超时从 10 秒压到 3 秒，超时文案「连接超时（3 秒），请检查地址/端口/网络」；工具执行仍是 45 秒
- **工具列表改为二级页**：测试成功后只在 MCP 区显示一行「工具（8 / 8 启用）›」，点进去才是列表 + 开关（顶部显示服务端信息），不再自动展开
- **V4 Pro 自动关闭服务端联网工具**（该模型不支持 deepseek_web_search，带上会 400）
- 版本 1.8.0 (28)

完整功能列表与用法见 [README](https://github.com/YYUN64/DeepSeekChat#readme)。
