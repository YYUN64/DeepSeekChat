## 修复（v1.8.1）

- **时间偏差友好提示**：服务端返回「时间戳过期」时，提示改成「手机时间与服务器相差超过 5 分钟，签名鉴权被拒绝。请开启「自动设置时间」后重试（设置 → 系统 → 日期和时间）」
- **连接失败文案口语化**：`connection closed` →「服务器未响应（连接被关闭），请确认服务器已启动、地址和端口正确」；`ECONNREFUSED` →「端口没有服务在监听…」；`UnknownHost` →「地址解析失败，请检查 IP 填写」；其它错误保留原文并附类型
- **「仅本次用普通对话」逃生按钮**：MCP 开着但连不上/没有可用工具时，错误条上出现该按钮（旁边小字「只影响这一次」）；点击后仅这一轮不带 MCP 工具发送，不写设置，下一轮仍按「MCP 必须在」执行
- **测试连接结果常驻**：不再用一闪而过的 snackbar；MCP 区显示「已连接 · 8 个工具」或红色失败原因，直到下次测试成功或手动关闭
- 版本 1.8.1 (29)
